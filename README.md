# inVectus

Negative search: find what is missing in a collection, describe what would fill the gap, and
verify it before claiming it doesn't exist. Desktop app (macOS, Windows, Linux) built with
Tauri 2, a Rust core and a React + TypeScript UI.

- Specification: [`SPEC.md`](SPEC.md)
- Progress: [`PROGRESS.md`](PROGRESS.md)
- Prototype and first benchmark: `~/Documents/Medical Paper Vector Database` (Python package `gapmap`)
